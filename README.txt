z-tower — Rapunzel : The Z Tower
เว็บไซต์เกมคณิตศาสตร์เรื่องตัวแปรสุ่ม การแจกแจงปกติ และค่า Z

วิธีใช้กับ GitHub Pages
1. สร้าง Repository ใหม่บน GitHub เช่น z-tower
2. อัปโหลดไฟล์ index.html นี้เข้า Repository
3. ไปที่ Settings > Pages
4. ใน Build and deployment เลือก Deploy from a branch
5. เลือก Branch: main และ Folder: / (root)
6. กด Save
7. รอสักครู่ แล้ว GitHub จะสร้างลิงก์เว็บไซต์ให้

ไฟล์หลักของเว็บไซต์คือ index.html
